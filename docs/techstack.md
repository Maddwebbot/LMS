<!-- FRONTEND -->

- HTML5 - structure and layout
- CSS3 - stling and UI design
- JavaScript (Vanilla JS) – frontend logic, DOM manipulation, event handling, filtering, animations

<!-- BACKEND -->

- Node.js - server-side runtime
- JavaScript – backend logic and API handling
- SQlite – relational database for storing books, users, and transactions

<!-- FRAMEWORK -->

- Electron – enables running my LMS as a cross-platform desktop app using web technologies with full access to the local file system and database.

<!-- DATABASE -->

- SQLite (better-sqlite3) – lightweight, file-based database used for CRUD operations and transactions

<!-- PACKAGE MANAGEMENT -->

- npm - dependency and script management

<!-- LIBRARIES / DEPENDENCIES -->

- better-sqlite3 – database queries and transactions

- Express.js – routing and API endpoints

- Body-parser / built-in Express middleware – handling request payloads

- chart.js installed in the system for visualization of data

- xlsx installed for exportation of data in xlsx

- qrcode creates qr code

- jsqr scannes qrcode in web cam

<!-- ARCHITECHTURE / APPROACH -->

- Client–Server architecture but it's offline.

- REST-style communication internally via IPC for frontend ↔ backend communication

- MVC-inspired separation (logic, data, UI separated)
